the app · dark, dense, keyboard-first

What it does

and nothing it doesn't

  • Save in one click

    The extension grabs the page you're on, every open tab, or a highlighted passage — and badges the tabs already on your shelf.

  • Collections and tags

    Group by project, filter by tag. Bulk-edit a hundred rows without a modal in sight.

  • Find it again

    Search titles, hosts and tags from the keyboard. The thing you saved in March is two keystrokes away.

  • Trash that waits

    Deleted rows sit in the trash until you say otherwise. Nothing leaves without a second look.

  • Snapshots and preview

    Keep the page as it was, then read it in a small window even when the site refuses to be framed.

  • A toolbox, your model

    Cleanup scans, tag merges, and page summaries via any OpenAI-compatible endpoint — or none at all.

  • Open to your tools

    A token-scoped REST API and an MCP endpoint, so scripts and assistants use the same shelf you do.

  • Installs as an app

    A PWA on the desktop and the phone, plus a browser extension. No store, no review queue.

  • One user: you

    No teams, no invites, no sharing model to reason about. Your instance answers to one login.

Run it where you like

One container and a volume. Put it behind your reverse proxy, point a subdomain at it, and it's yours. Nothing calls home, because there's no home to call.

  • data lives in a single volume you can tar
  • export everything as JSON or HTML whenever you want
  • page snapshots and daily JSON backups in the same volume
  • no telemetry, no third-party fonts, no external requests
